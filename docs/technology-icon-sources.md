# Technology icon sources

Audited 2026-10-24. This supplement preserves all 24 existing technology IDs, categories, and project associations. All runtime images are local; no icon package or runtime network access is required. Descriptions are neutral technical definitions linked to official documentation in src/data/technology-details.ts. They assert no proficiency, experience, or project usage.

## Pinned sources and geometry

Simple Icons **16.35.0** was verified against its [official release](https://github.com/simple-icons/simple-icons/releases/tag/16.35.0), annotated tag 37ada29537474766bd71595af691abfe295798ef and commit **ed9a5192b24ad2f169bf1009931da0df27d5a49a**, including that commit's package version and data/simple-icons.json. The 18 distinct Simple Icons marks serve 19 IDs because React Native reuses React geometry, with a React Native title/caption, matching the official upstream duplicate alias. Source SVG path data is preserved exactly. Only a root fill is added for standalone image rendering. Next.js, GitHub, and Vercel use white monochrome variants on the dark gallery; original source hex values remain recorded. All other Simple Icons fills use their source brand hex. The C mark is the established community C-language mark carried by Simple Icons, not an ISO/WG14 institutional logo.

C# uses the [official .NET language icon](https://raw.githubusercontent.com/dotnet/brand/91845f6ddf2123b3bb1bfd1b6a386d9ce02b43aa/logo/language-icons/csharp-72.svg) at commit 91845f6ddf2123b3bb1bfd1b6a386d9ce02b43aa, byte-for-byte, including its purple gradient. Its [language-icon instructions](https://raw.githubusercontent.com/dotnet/brand/91845f6ddf2123b3bb1bfd1b6a386d9ce02b43aa/logo/language-icons/README.md) and repository CC0 license are preserved.

Power BI uses [Microsoft's genuine SVG](https://raw.githubusercontent.com/microsoft/PowerBI-Icons/24f1db8bdfab951c25db591772140d2f4ec5bc1e/SVG/Power-BI.svg) at commit 24f1db8bdfab951c25db591772140d2f4ec5bc1e, byte-for-byte, including its viewBox, mask, gradient, filter and aspect ratio. Microsoft and contributors license repository content under CC BY 4.0; the original LICENSE, LICENSE-CODE and README legal notices are preserved. Credit: **Microsoft and contributors, Power BI icon, CC BY 4.0, unmodified**. This documents the named product; it does not imply endorsement. The manifest hex #F6D751 is an actual source-gradient color, not a claim that this multicolor artwork has one official flat color.

NextAuth uses the **official original PNG** locally as /technology-icons/nextauth.png, the approved official-image alternative to an SVG. It is pinned to next-auth@4.24.11, commit 6bca388f46636d1598a430ba6624e1201e70f213, with the ISC LICENSE and Iain Collins copyright preserved. The repository's docs configuration selects img/logo/logo-xs.png; logo-sm.png is the larger version in the same official logo directory. docs/static/img/logo.svg is an unrelated Docusaurus dinosaur and is deliberately excluded. No vector tracing, fabricated shield, embedded raster SVG wrapper, recoloring, or remote image request is used. Its multicolor artwork has no verified single original brand hex, so hex is null.

## Honest text fallbacks

- **SQL**: SQL is a generic standardized database language, not one database brand. No single canonical SQL mark was identified; another database logo would misrepresent it. [SQL standard](https://www.iso.org/standard/76583.html).
- **Java**: Java is absent from Simple Icons 16.35.0. Oracle Java logo and Dev.java affinity terms are limited permissions, not an open artwork license; affinity marks require an active Dev.java link and prohibit resizing/animation. Use plain Java text rather than a substitute mascot or unlicensed coffee-cup mark. [Oracle trademark guidance](https://www.oracle.com/legal/trademarks.html), [official affinity terms](https://dev.java/community/affinity/). No invented or third-party logo was used.

C#, Java and Power BI were confirmed absent from the pinned Simple Icons metadata. Official dotnet/brand, Microsoft PowerBI-Icons, Microsoft Power Platform guidance and Oracle/Dev.java sources were checked before choosing official artwork or text.

## Reproduction and offline validation

Run node scripts/fetch-technology-icons.mjs --fetch only as an explicit maintenance operation with network/write permission; it writes only these generated asset/data/provenance files and its raw-download cache. It never edits existing technologies.ts, projects.ts, dependencies, UI or tests. Run node scripts/fetch-technology-icons.mjs --verify for offline read-only coverage, schema, SHA-256, exact path-data, SVG allowlist/reference, PNG signature and original-data baseline checks. XML parsing and isolated TypeScript checks can be performed without launching the application. No browser, build, app test, Git command, or deployment is part of this asset task.
