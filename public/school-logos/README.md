# School logos

The supplied school logos are wired using these exact filenames (PNG and JPEG are supported):

- aloran-christian-school-inc.jpg (Kindergarten and Grade 1–2)
- binlod-elementary-school.jpg (Grade 3 before semester break)
- river-of-knowledge-foundation-academy-inc.jpg (Grade 3 after semester break – Grade 5)
- central-philippine-university.jpg (Grade 6–9)
- christian-learning-center-of-argao-cebu-inc.png (Grade 10)
- university_of_cebu_main_campus.jpg (Grade 11 – 4th Year College)

Nursery currently has no known school or expected logo.

The six school logos were supplied by Haggai. No logos are downloaded or generated by the website.
Transparent PNGs and standard JPEGs are supported. Images retain their proportions as large, centered decorative watermarks inside the Education detail card. Low opacity and CSS-only monochrome blending keep the original artwork sharp while suppressing white image canvases; source files are never edited.
Missing logos and Nursery use a clean card background without a replacement icon.

After adding or replacing logos, refresh the development page (restart the dev server if needed).
Run a fresh production build before publishing: file presence is checked at build time.
Keep these filenames and capitalization unchanged. The original logo files are never processed or overwritten.
