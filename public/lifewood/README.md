# Lifewood internship photographs

Place original JPG/JPEG, PNG, WebP or AVIF photographs here. The application never edits originals.
Suggested names: internship-01.jpg, internship-02.jpg, internship-03.jpg, internship-04.jpg.
Use letters, numbers, hyphens or underscores in filenames.

Adding a file does NOT publish it. Register its actual filename in src/data/lifewood-photos.json:
[
  { "filename": "internship-01.jpg", "publication": "pending", "alt": "A verified description", "caption": "Optional verified caption" }
]
Only use "approved" after public-use permission and privacy checks are confirmed, including people and visible documents/screens. "private", "pending", missing/unlisted entries are withheld. Keep filenames unique. Never invent descriptions or photo associations.

Reload the development page or rebuild after changes. Optimized, metadata-stripped derivatives are cached in .cache/lifewood-media and served at /experience-media/. Raw originals are blocked in development and removed from generated production output. Source photographs remain untouched.
